🗃 إضافة متصفح ArchiveBox

تتيح هذه الإضافة إرسال علامات تبويب منفردة أو عناوين تطابق أنماطًا محددة إلى خادم ArchiveBox الخاص بك لحفظها دون اتصال. ومن فوائدها:

  • امتلك بياناتك: احفظ محتوى الويب المهم واحمه من الروابط المعطلة.
  • احم بياناتك: احتفظ بنسخ دون اتصال بصيغ شائعة ومتينة.
  • استخدم بياناتك: نظّم الإشارات المرجعية وابحث في السجل واربط الأنظمة الأخرى عبر واجهات ArchiveBox.

احصل على الإضافة

  • متصفحات Chrome / Brave / أخرى مبنية على Chromium
  • متصفحات Firefox / Waterfox / Tor Browser / أخرى مبنية على Firefox
  • Microsoft Edge
  • Safari / iOS Safari (مضمنة داخل ArchiveBox.app لـ iOS/macOS)

الميزات

  • 📸 احفظ الصفحة الحالية بزر شريط الأدوات أو اختصار لوحة المفاتيح أو قائمة النقر بالزر الأيمن.
  • 🏛️ أرسل العناوين إلى خادم ArchiveBox الخاص بك لحفظ المواقع.
  • 🏷️ ابحث في العناوين المحفوظة ورتّبها وضع وسومًا لها وأدرها في مكان واحد.
  • ⚙️ أرشف الصفحات المطابقة للأنماط تلقائيًا باستخدام قوائم السماح والمنع.
  • 📥 راجع العناوين واستوردها دفعة واحدة من سجل أو إشارات Chrome وEdge وFirefox.
  • 🧭 استورد الإشارات المرجعية وقائمة القراءة وسجل Safari من الملفات المصدّرة.
  • 🖼️ احتفظ بلقطات محلية، بما فيها لقطات الصفحة الكاملة عند منح الإذن.
  • 📄 احفظ نسخ MHTML محلية. (Chrome وEdge.)
  • 📑 احفظ نسخ HTML مع إضافة SingleFile المتصلة.
  • 📤 صدّر العناوين بصيغة CSV أو JSON واللقطات بصيغة PNG والصفحات بصيغة HTML أو MHTML أو اجمعها في ZIP.
  • 👤 اختر ملفات تعريف الارتباط وإعدادات المتصفح لمزامنتها مع ملف مصادقة ArchiveBox للمواقع التي تتطلب تسجيل الدخول.
  • 🧹 اختر مدة الاحتفاظ بالنسخ المحلية ونظّفها بعد إرسالها بنجاح إلى الخادم.
  • 🌐 استخدم الإضافة بالإنجليزية أو الإسبانية أو الصينية المبسطة.

الاستيراد من Safari

لا يتيح Safari الإشارات المرجعية بالجملة أو السجل عبر واجهات WebExtension API. استخدم تصدير بيانات التصفح: على Mac اختر ملف ← تصدير بيانات التصفح إلى ملف؛ على iPhone/iPad اختر Settings → التطبيقات → Safari → Export. حدد الإشارات المرجعية وقائمة القراءة والسجل حسب التوفر.

في خيارات الإضافة ← استيراد عناوين URL بالجملة, اختر بيانات Safari المراد استيرادها ونطاق تاريخ السجل، ثم حدد ملف ZIP المُصدّر (أو ملفات HTML/JSON المستخرجة). راجع عناوين URL، وحدد ما تريد الاحتفاظ به، وانقر استيراد المحدد. تُعلّم عناوين URL المحفوظة مسبقاً كمكررات. يحتفظ السجل بوقت الزيارة الأصلي. تُحلل الملفات محلياً، وتُتجاهل كلمات المرور وبطاقات الدفع، وتدخل الاستيرادات إلى قائمة عناوين URL المحفوظة نفسها التي تستخدمها مصادر الاستيراد الأخرى. استخدم إجراءات المزامنة الحالية لإرسالها إلى خادمك.

النسخ المحلية

عند تفعيل حفظ الالتقاط المحلي في صفحة الخيارات، تخزن الإضافة آثار الالتقاط في تخزين OPFS المحلي للإضافة قبل ظهور النافذة المنبثقة:

  • لقطة شاشة للصفحة كاملة: snapshots/YYYYMMDD/example.com/{uuid}/chrome_extension_screenshot/screenshot.png
  • لقطة MHTML: snapshots/YYYYMMDD/example.com/{uuid}/chrome_mhtml/snapshot.mhtml

تُزال النسخ المحلية من OPFS بعد 30 يوماً افتراضياً؛ ويمكنك ضبط الإضافة للاحتفاظ بها إلى أجل غير مسمى أو إزالتها فور استلام الخادم لعنوان URL.

الإعداد

  1. قم بإعداد ArchiveBox الخادم وتأكد من إمكانية وصول الجهاز الذي تتصفح منه إليه
  2. في ArchiveBox 0.9.0، افتح المسؤول ← API ← مفاتيح API ← إنشاء مفتاح API, أنشئ مفتاحاً وانسخه.
  3. افتح خيارات الإضافة ← الإعدادات، الصق المفتاح في مفتاح API, وأدخل عنوان URL لخادم ArchiveBox (مثلاً https://archivebox.example.com) في عنوان URL للخادم. احفظ الإعدادات واختبر الاتصال.
  4. ✅ اختبر ذلك بالنقر بزر الفأرة الأيمن على أي صفحة واختيار Save to ArchiveBox, أو بالنقر على أيقونة الإضافة في شريط القوائم.

التطوير

✨ ساهم في الأصل بواسطة TJ Horner (@tjhorner)، ويتولى صيانتها الآن @benmuth و ArchiveBox الفريق.

إذا رغبت في المساهمة في هذه الإضافة (أو بنائها لنفسك فقط)، فستحتاج إلى تنزيل وتثبيت Node.js و pnpm.

git clone https://github.com/ArchiveBox/archivebox-browser-extension
cd archivebox-browser-extension/

pnpm install
pnpm compile
pnpm build
pnpm build:edge
pnpm build:firefox
pnpm build:safari

للتطوير المحلي:

pnpm dev           # Chrome / Chromium
pnpm dev:edge      # Edge
pnpm dev:firefox   # Firefox
pnpm dev:safari    # Safari WebExtension build

لبناء محلي بطابع الإنتاج، حمّل .output/chrome-mv3 إلى Chrome/Chromium باستخدام تحميل إضافة غير مضغوطة الواجهة، حمّل .output/edge-mv3 في Edge باستخدام edge://extensions، حمّل .output/firefox-mv3 في Firefox باستخدام about:debugging، أو حمّل .output/safari-mv3 في Safari عبر الإعدادات ← المطور ← إضافة إضافة مؤقتة.

للتحقق من الاحتفاظ المحلي مع استجابات الخادم الفعلية ودقيقة واحدة حقيقية، شغّل خادم ArchiveBox مؤقتاً بلا عمال أرشفة (لتبقى الإرسالات في قائمة الانتظار)، وابنِ الإضافة، وشغّل:

ARCHIVEBOX_TEST_SERVER=http://127.0.0.1:5797 \
ARCHIVEBOX_TEST_KEY_FILE=/path/to/disposable-server-api-key \
node scripts/test-retention-live.mjs

يستورد الاختبار المباشر الإشارات المرجعية عبر واجهة الخيارات، ويرسلها، ويفحص حفظ حالة انقطاع الاتصال/الخادم المفقود، ويتحقق من حذف OPFS والبيانات الوصفية، ويعيد تشغيل عامل الخدمة، وينتظر انتهاء الصلاحية التلقائي بعد إعادة الإرسال. ينشئ سجلات اختبار على الخادم ويحذف أحد سجلاته لاختبار لقطة مفقودة؛ استخدم مجموعة مؤقتة. تُجرى فحوصات الإعدادات الافتراضية/الاستمرارية والتخطيط باستخدام pnpm exec playwright test tests/retention.test.ts tests/options-responsive.test.ts.

إضافات أخرى للأرشفة

إضافات متصفح أخرى تؤرشف الويب وقد تكون أنسب إذا لم يلائمك ArchiveBox.

  • ArchiveWeb.page (إضافة أرشفة فائقة الدقة من Webrecorder)
  • SingleFile (إضافة رائعة لحفظ الصفحات في ملف واحد .html ملف، مدمج في ArchiveBox أصلاً)
  • Hypothesis (إضافة تركز على التعليق، لكنها تدعم الأرشفة أيضاً)
  • Memex (مشروع آخر يركز على التعليق ويدعم الأرشفة)
  • Save Page WE (إضافة Firefox تحفظ صفحات الويب أيضاً كملف HTML واحد)

مشاريع ArchiveBox المساعدة

مشاريع أخرى تساعد في إدخال عناوين URL إلى ArchiveBox من مصادر متنوعة.

  • https://github.com/layderv/archivefox (إضافة Firefox من مساهمين)
  • https://github.com/Gertje823/ArchiveboxTelegramBot (روبوت Telegram لإرسال عناوين URL إلى ArchiveBox)
  • https://github.com/TheCakeIsNaOH/xbs-to-archivebox (نزّل إشاراتك المرجعية من xBrowserSync، وفلترها، واحفظها في ArchiveBox)
  • https://github.com/emschu/archivebox-quick-add (أداة Go لإضافة الروابط إلى ArchiveBox)
  • https://github.com/FracturedCode/archivebox-reddit (نسخ تعليقات ومنشورات Reddit المحفوظة احتياطياً تلقائياً إلى ArchiveBox)
  • https://github.com/dbeley/reddit_export_userdata (أداة Python قديمة لأرشفة محتوى Reddit إلى ArchiveBox)
  • https://github.com/jess-sol/reddit-exporter (تصدير بيانات Reddit إلى ArchiveBox)
  • https://github.com/jonesd/archivebox-pinboard-tranformer (تصدير الروابط من Pinboard إلى ArchiveBox)
  • https://github.com/agg23/archivebox-url-forwarder (WebExtension قديمة لإعادة توجيه عناوين URL إلى ArchiveBox)

🗃 ArchiveBox 浏览器扩展

此扩展可将单个浏览器标签页或符合指定规则的网址发送到您的 ArchiveBox 实例以便离线保存。它有以下优点：

  • 掌控自己的数据：保存重要网页内容，避免链接失效。
  • 保护数据：以常见、耐久的格式保存离线副本。
  • 使用数据：整理书签、全文搜索浏览历史，并通过 ArchiveBox API 连接其他系统。

获取扩展

  • Chrome / Brave / 其他基于 Chromium 的浏览器
  • Firefox / Waterfox / Tor Browser / 其他基于 Firefox 的浏览器
  • Microsoft Edge
  • Safari / iOS Safari （已捆绑在 ArchiveBox.app for iOS/macOS 中）

功能

  • 📸 通过工具栏按钮、键盘快捷键或右键菜单保存当前页面。
  • 🏛️ 将网址发送到您自己的 ArchiveBox 服务器以长期保存网站。
  • 🏷️ 集中搜索、排序、标记和管理已保存的网址。
  • ⚙️ 根据所选网址规则和允许/拒绝列表自动归档网页。
  • 📥 查看并批量导入 Chrome、Edge 和 Firefox 的历史记录或书签网址。
  • 🧭 从 Safari 导出的 ZIP、HTML 或 JSON 文件导入书签、阅读列表和历史记录。
  • 🖼️ 保存本地截图；授予权限后可截取完整页面。
  • 📄 保存本地 MHTML 副本。（Chrome 和 Edge。）
  • 📑 安装并连接 SingleFile 扩展后保存 HTML 副本。
  • 📤 将网址导出为 CSV 或 JSON、截图导出为 PNG、页面导出为 HTML 或 MHTML，也可全部打包为 ZIP。
  • 👤 为需要登录的网站选择要同步到 ArchiveBox 身份验证配置中的 Cookie 和浏览器设置。
  • 🧹 选择本地副本的保留时间，并可在成功提交到服务器后清理。
  • 🌐 扩展支持英语、西班牙语和简体中文。

从 Safari 导入

Safari 不通过 WebExtension API 暴露批量书签或历史记录。 使用 Apple 的 浏览数据导出：在 Mac 上选择 文件 → 将浏览数据导出为文件；在 iPhone/iPad 上选择 Settings → 应用 → Safari → Export。选择书签、阅读列表和历史记录（如果可用）。

在 扩展选项 → 批量导入 URL，选择要导入的 Safari 数据和历史记录日期范围，然后选择导出的 ZIP（或解压后的 HTML/JSON 文件）。检查 URL，选择要保留的项目，然后点击 导入所选内容。已有的已保存 URL 会标记为重复项。历史记录保留原始访问时间。文件在本地解析，密码和支付卡会被忽略，导入内容会进入与其他导入源相同的已保存 URL 列表。使用现有的同步操作将其提交到服务器。

本地捕获

在选项页面启用本地捕获保存后，扩展会在显示弹窗前将捕获产物存储在浏览器扩展本地 OPFS 中：

  • 整页截图： snapshots/YYYYMMDD/example.com/{uuid}/chrome_extension_screenshot/screenshot.png
  • MHTML 快照： snapshots/YYYYMMDD/example.com/{uuid}/chrome_mhtml/snapshot.mhtml

OPFS 中的本地副本默认在 30 天后删除；你可以配置扩展永久保留它们，或在服务器收到 URL 后立即删除。

设置

  1. 设置一个 ArchiveBox 并确保浏览机器可以访问它
  2. 在 ArchiveBox 0.9.0 中打开 管理员 → API → API 密钥 → 创建 API 密钥，创建密钥并复制它。
  3. 打开 扩展选项 → 配置，将密钥粘贴到 API 密钥，然后输入你的 ArchiveBox 服务器 URL（例如 https://archivebox.example.com），在 服务器 URL。保存配置并测试连接。
  4. ✅ 右键点击任意页面并选择来测试 Save to ArchiveBox，或点击菜单栏中的扩展图标。

开发

✨ 最初由以下人员贡献 TJ Horner (@tjhorner)，现由以下人员维护： @benmuth 以及 ArchiveBox 团队。

如果你希望为此扩展贡献代码（或只为自己构建），需要下载并安装 Node.js 和 pnpm.

git clone https://github.com/ArchiveBox/archivebox-browser-extension
cd archivebox-browser-extension/

pnpm install
pnpm compile
pnpm build
pnpm build:edge
pnpm build:firefox
pnpm build:safari

本地开发：

pnpm dev           # Chrome / Chromium
pnpm dev:edge      # Edge
pnpm dev:firefox   # Firefox
pnpm dev:safari    # Safari WebExtension build

对于生产风格的本地构建，请加载 .output/chrome-mv3 使用以下内容加载到 Chrome / Chromium 加载已解压的扩展 界面，加载 .output/edge-mv3 到 Edge，使用 edge://extensions，加载 .output/firefox-mv3 到 Firefox，使用 about:debugging，或加载 .output/safari-mv3 在 Safari 中使用设置 → 开发者 → 添加临时扩展。

要用真实服务器响应和真实的一分钟时钟验证本地保留，请启动一个不带存档工作线程的一次性 ArchiveBox 服务器（使提交保持排队），构建扩展，然后运行：

ARCHIVEBOX_TEST_SERVER=http://127.0.0.1:5797 \
ARCHIVEBOX_TEST_KEY_FILE=/path/to/disposable-server-api-key \
node scripts/test-retention-live.mjs

实时测试通过选项界面导入书签，提交它们，检查断开连接/缺少服务器时的保留情况，验证 OPFS 和元数据删除，重启服务工作线程，并等待重新提交后的自动过期。它会创建服务器测试记录，并删除自己的一个记录来测试缺少快照的情况；请使用一次性收藏。UI 默认值/持久性和布局检查使用 pnpm exec playwright test tests/retention.test.ts tests/options-responsive.test.ts.

其他网页归档扩展

其他同样能进行网页存档的浏览器扩展，如果 ArchiveBox 不适合你的需求，可能更适合你。

  • ArchiveWeb.page （Webrecorder 提供的超高保真存档扩展）
  • SingleFile （一个很棒的扩展，可将页面保存为单个 .html 文件，已内置于 ArchiveBox）
  • Hypothesis （专注于批注但也支持存档的扩展）
  • Memex （另一个专注于批注且支持存档的项目）
  • Save Page WE （也将网页保存为单个 HTML 文件的 Firefox 扩展）

其他 ArchiveBox 辅助项目

其他帮助从各种来源将 URL 导入 ArchiveBox 的项目。

  • https://github.com/layderv/archivefox （用户贡献的 Firefox 扩展）
  • https://github.com/Gertje823/ArchiveboxTelegramBot （用于向 ArchiveBox 发送 URL 的 Telegram 机器人）
  • https://github.com/TheCakeIsNaOH/xbs-to-archivebox （从 xBrowserSync 下载书签、筛选后保存到 ArchiveBox）
  • https://github.com/emschu/archivebox-quick-add （用于向 ArchiveBox 添加链接的 Go 工具）
  • https://github.com/FracturedCode/archivebox-reddit （自动将已保存的 Reddit 评论、帖子等备份到 ArchiveBox）
  • https://github.com/dbeley/reddit_export_userdata （用于将 Reddit 内容存档到 ArchiveBox 的旧版 Python 工具）
  • https://github.com/jess-sol/reddit-exporter （将 Reddit 数据导出到 ArchiveBox）
  • https://github.com/jonesd/archivebox-pinboard-tranformer （将 Pinboard 中的链接导出到 ArchiveBox）
  • https://github.com/agg23/archivebox-url-forwarder （用于将 URL 转发到 archivebox 的旧版 WebExtension）
